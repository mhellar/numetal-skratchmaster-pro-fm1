NU//METAL SKRATCHMASTER PRO

A robot turntablist with a nu metal band, for the M-VAVE FM-1. Version 2.0.

INSTALL

This browser has no Web MIDI. Open this page in Chrome or Edge on a computer.
  1. Plug the FM-1 into this computer with a USB data cable and switch it on.
  2. Close other music apps that might be using it (a DAW, the FM-1 editor).
  3. Press Install and allow MIDI access when the browser asks (SysEx is how firmware travels).
  4. Do not unplug it while it writes (about a minute). It restarts by itself.

WHAT IT DOES

    
The FM-1 becomes a deck. SAM, the 1982 Software Automatic Mouth, says 27 words onto a virtual record, and you
      scratch them with the keys and the jog wheel. Behind you, a drop-tuned band plays double-tracked chugging guitars,
      a bass and a 12-piece kit locked to ten grooves. In RAP MODE the robot is the MC: verses that fit the beat, then a
      growled hook.

    
    
      
  • A real LFO: 11 synced rates, 7 shapes, 6 destinations

  • 17 scratch techniques and COMBO routines

  • HAMSTER, crossfader CURVE, motor TORQUE

  • TONE PLAY: the keys as a pitch fader
